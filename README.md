## 🎯 Apa itu Website Ucapan?

Website Ucapan adalah templat website statis berbasis **100% HTML** yang dirancang untuk menampilkan pesan ucapan selamat secara digital. Cocok digunakan untuk:
- 🎂 Ucapan ulang tahun yang personal
- 💍 Undangan atau ucapan pernikahan digital
- 🎊 Ucapan hari raya (Lebaran, Natal, Tahun Baru, dll.)
- 🎓 Ucapan wisuda atau kelulusan

Proyek ini dibuat sangat minimalis agar **ringan, cepat dimuat**, dan dilengkapi dengan **GitHub Actions** untuk proses deploy ke GitHub Pages secara otomatis setiap kali ada perubahan.

## ✨ Fitur Utama

| Fitur | Deskripsi |
|---------|-------------|
| ⚡ **Super Ringan** | Dibangun murni dengan HTML, tanpa framework berat atau dependensi eksternal |
| 🚀 **Deploy Otomatis** | Dilengkapi workflow GitHub Actions, cukup `git push` dan website langsung online |
| 🎨 **Mudah Dikustomisasi** | Struktur kode yang bersih, mudah untuk mengganti teks, warna, atau menambahkan CSS/JS |
| 📱 **Responsif** | Tampilan menyesuaikan dengan baik di perangkat desktop maupun mobile |
| 🆓 **Gratis Selamanya** | Di-hosting di GitHub Pages tanpa biaya server atau domain |
